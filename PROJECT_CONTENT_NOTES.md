## LEBWPOLISH
A Polish-learning platform designed around small daily activities toward B1 proficiency. React 19 and Firebase power guided missions, spaced-repetition cloze games, writing practice, grammar, reading, role-play, and cross-device progress syncing. Includes an offline standalone game, regression tests, and Netlify deployment.

Stack: React 19, Firebase, Netlify
Repository: https://github.com/Byadiso/lebwpolish

## Healthy Watcher
A zero-server-cost website monitoring system using Python, SQLite, and Streamlit. GitHub Actions checks sites every 30 minutes, sends Telegram outage and recovery alerts, and feeds an uptime and response-time dashboard with invite-only access and audit logs.

Stack: Python, SQLite, Streamlit, GitHub Actions
Repository: https://github.com/Byadiso/healthy-watcher

## HireMeD
An automated job-search pipeline for the Polish IT market. It gathers Adzuna listings, extracts full descriptions with Playwright, translates Polish listings, ranks matches against a resume using cosine similarity, and sends high-scoring roles to Telegram. Results are logged to Excel and displayed in Streamlit.

Stack: Python, Playwright, Streamlit, Adzuna API
Repository: https://github.com/Byadiso/HireMeD

## Rwanda Tourism Service-Gap Finder
A Python and Playwright research tool that audits Google Maps listings in Kigali, Musanze, Gisenyi, and Butare. It identifies tourism businesses with missing websites, limited reviews, or low ratings, labels potential service gaps, and exports leads to Excel. Documentation notes scraping terms-of-service considerations.

Stack: Python, Playwright, Excel
Repository: https://github.com/Byadiso/service_gap_finder

## Stonka Hunter
A computer-vision tool for identifying Colorado potato beetles from camera feeds or uploaded photos. It uses a custom-trained YOLOv8 model on a 12-class insect dataset, priority pest alerts, weather and location context, a detection gallery, and adjustable confidence settings.

Stack: Python, YOLOv8, OpenCV, Streamlit
Repository: https://github.com/Byadiso/Stonka-Hunter

## Rwanda Flight Price Tracker
An automated flight-deal tracker for routes between Poland or Germany and Kigali during July–August 2026. It compares date combinations through the Duffel API, converts prices to PLN, checks every 30 minutes via GitHub Actions, and sends Telegram alerts with Google Flights links.

Stack: Python, Duffel API, GitHub Actions
Repository: https://github.com/Byadiso/kigali_flight
